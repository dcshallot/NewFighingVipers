## 来源与设计

- [ ] 所有采用参考均登记在 `honey-reference-manifest.csv`。
- [ ] 每项参考的权利状态和允许用途已审核。
- [ ] AI 补充与原作证据明确分层。
- [ ] 没有来源不明内容进入正式网格或纹理。
- [ ] 当前模型只覆盖 Honey 正常状态。
- [ ] 关键轮廓符合已冻结的 `CHARACTER_BIBLE.md`。

## 固定视角

- [ ] 正面比例和色块通过。
- [ ] 侧面头、胸、骨盆、腿和靴子轮廓通过。
- [ ] 背面头发、背带、裙摆和靴子关系通过。
- [ ] 左右 3/4 无明显不对称错误。
- [ ] 游戏默认镜头下可读。
- [ ] 踢击和低机位轮廓可读。

## 几何与拓扑

- [ ] 无非预期非流形、重叠面、内部悬空面和翻转法线。
- [ ] transform、尺度和朝向符合规格。
- [ ] 肩、肘、腕、髋、膝、踝边流适合变形。
- [ ] 双马尾、裙摆和袖口具有明确控制结构。
- [ ] LOD0 triangle、材质槽和 renderer 数量在预算内。
- [ ] 高模、参考平面和试验件未进入导出 collection。

## UV 与材质

- [ ] UV 无非预期重叠或越界。
- [ ] texel density 合理一致。
- [ ] 纹理尺寸和通道符合规格。
- [ ] 脸、发梢、裙边和蕾丝无明显脏边。
- [ ] 中性光照下颜色符合角色规格。
- [ ] Blender 与 Unity URP 的材质差异可接受。
- [ ] 透明和 cutout 区域无明显排序问题。

## 骨架与变形

- [ ] 骨架层级和命名稳定。
- [ ] Unity Humanoid 映射符合预期。
- [ ] 单顶点骨骼影响符合预算。
- [ ] idle 无塌陷或静态穿模。
- [ ] walk 无明显脚滑、裙摆或头发异常。
- [ ] hit 姿势无肩、胸、髋部严重塌陷。
- [ ] kick 姿势无大面积穿模或权重拉爆。
- [ ] 辅助骨骼在重复导出后行为一致。

## Unity 导入与性能

- [ ] 从干净工作区可重复导出和导入。
- [ ] Unity 中尺度、前向、脚底和 pivot 正确。
- [ ] Prefab、材质、Avatar、Animator 和 `.meta` 完整。
- [ ] Console 无与角色相关的 error。
- [ ] 固定验证场景可重复运行。
- [ ] 单角色 CPU、GPU、内存指标已记录。
- [ ] 具有扩展到双角色与竞技场的性能余量。

## 版本与交付

- [ ] 源文件和批准导出已登记在 `honey-asset-manifest.csv`。
- [ ] SHA-256、owner、评审结论和 commit/tag 闭环。
- [ ] 正式二进制资产由 Git LFS 管理。
- [ ] 不可合并源文件已解除或移交 LFS lock。
- [ ] 正式主文件存在独立备份。
- [ ] 发布快照不包含 `LocalData/` 或受限素材。
