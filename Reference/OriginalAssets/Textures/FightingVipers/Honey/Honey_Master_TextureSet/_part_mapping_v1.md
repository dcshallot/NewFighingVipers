# Honey Normal Texture Part Mapping v1

## Scope
- 只整理 Honey 常态/非破甲贴图。
- 本表是“贴图归属假设表”，不是最终 UV 锁定表。
- `Confidence` 只表示当前基于贴图形状 + 你提供的战斗截图 + P1/P2 变体关系的判断强度，不等于已经在模型 UV 上验证过。
- 下一步要用假彩色材质反贴模型，把 `Mid/Low` 项逐个拉高或修正。

## Confidence Legend
- `High`：贴图形状和游戏截图高度一致，且部位语义清楚。
- `Mid`：大方向基本对，但左右/前后/具体哪一片 UV 还没锁。
- `Low`：目前只是形状像，存在明显串位风险，必须假彩色验证。
